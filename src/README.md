# Trivia Survey Visualizer

An interactive data visualization tool built with React and Recharts that displays trivia question distributions from the Open Trivia Database API.

## 🚀 Live Demo

[View Live App](https://zara-afreen.github.io/trivia-survey-visualizer/)

## 📋 Features

- ✅ Fetches 50+ questions from Open Trivia DB API
- ✅ Interactive category filtering with multi-select checkboxes
- ✅ Bar chart visualization of questions by category
- ✅ Pie chart visualization of questions by difficulty
- ✅ Real-time summary statistics
- ✅ Clean, responsive UI with modern design

## 🛠️ Technologies Used

- **React** - Frontend framework with functional components and hooks
- **TypeScript** - Type-safe JavaScript
- **Recharts** - Chart library for data visualization
- **Tailwind CSS** - Utility-first CSS framework
- **shadcn/ui** - UI component library
- **Vite** - Build tool and development server
- **Open Trivia DB API** - Trivia questions data source

## 📊 Visualizations

1. **Questions by Category** - Bar chart showing distribution across different trivia categories
2. **Questions by Difficulty** - Pie chart breaking down easy, medium, and hard questions

## 🎯 Project Purpose

This project was created as part of the JetBrains Survey Visualizer internship application to demonstrate:
- Working with React and real API data
- Building clean and intuitive UI/UX
- Creating interactive data visualizations
- Deploying a working prototype

## 🚀 Local Development

1. Clone the repository:
```bash
git clone https://github.com/zara-afreen/trivia-survey-visualizer.git
cd trivia-survey-visualizer
```

2. Install dependencies:
```bash
npm install
```

3. Run the development server:
```bash
npm run dev
```

4. Open your browser and navigate to `http://localhost:5173`

## 📦 Building for Production

```bash
npm run build
```

The production-ready files will be in the `dist` folder.
